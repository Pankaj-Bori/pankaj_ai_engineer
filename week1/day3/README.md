# Day 3: Prompt Token Usage

This project demonstrates how to send multiple prompts to the Groq API and
measure token usage for each response.

## Features

- Sends three prompts to a Groq language model
- Counts prompt tokens
- Counts completion tokens
- Counts total tokens
- Displays the response finish reason

## Requirements

- Python 3.11 or later
- `uv`
- A Groq API key
